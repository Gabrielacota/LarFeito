# LarFeito

Aplicativo mobile de gamificação para gestão e divisão justa de tarefas domésticas familiares.

## Sobre o Projeto

O LarFeito é um aplicativo mobile focado na organização e divisão de tarefas domésticas entre os membros de uma família. Utilizando elementos de gamificação, o aplicativo incentiva a colaboração diária, elimina a sobrecarga individual e substitui cobranças por reconhecimento prático e recompensas significativas.

## O Problema

Frequentemente, a realização das tarefas domésticas fica centralizada e destinada desproporcionalmente às mulheres da casa, gerando esgotamento e sobrecarga física e mental. Além disso, a falta de uma divisão clara do trabalho gera constantes conflitos entre os membros da família, principalmente entre irmãos.

## A Solução

O LarFeito propõe um sistema de gamificação que distribui as atividades da casa de forma justa entre todos os integrantes, fortalecendo a colaboração, a valorização do trabalho doméstico e o sentimento de reconhecimento.

**Como funciona:**
* **Pontuação:** A realização de cada tarefa gera pontos configurados de acordo com o esforço e o tempo necessário.
* **Ranking Semanal:** Painel de acompanhamento do progresso de cada integrante em tempo real.
* **Recompensas Reais:** Os pontos podem ser trocados por prêmios personalizados e acessíveis à realidade da família (desde escolher o filme do fim de semana até ganhar um dia de folga da louça).

## Pré-requisitos

* Android Studio Iguana (ou superior)
* JDK 17+
* Emulador Android ou dispositivo físico com a Depuração USB ativada

## Como Executar o Projeto

1. Clone o repositório:
```text
git clone https://github.com/Gabrielacota/LarFeito.git
```

2. Acesse a pasta do projeto:
```text
cd larfeito
```

3. Abra o projeto no Android Studio e aguarde a sincronização das dependências do Gradle.

4. Execute o aplicativo:
Selecione o emulador ou dispositivo físico e clique em Run
